# NEORV32 software for the KIT SoC Lab Arduino platform

GENERATED by arduino/tools/make_board_package.py from ext/neorv32 of the firmware
repo (NEORV32 CHANGELOG top entry: 1.11.0 (22.01.2025)). BSD-3-Clause, see LICENSE.

- sw/lib/include, sw/lib/source: the NEORV32 drivers (all of them are compiled and
  linked, as common.mk does; --gc-sections drops the unused code)
- sw/common/crt0.S: start-up code
- sw/common/neorv32_arduino.ld: sw/common/neorv32.ld with ". = ALIGN(4);" in front of
  __init_array_start / __fini_array_start (arduino/build.mk: with the C extension
  .text may end on a 2-byte boundary and crt0 would read the constructor table
  2 bytes early)
